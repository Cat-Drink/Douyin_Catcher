# v0.2.1 CI/CD 首次运行 debug 记录

**时间**: 2026-07-27 10:41:41
**触发**: v0.2.1 CI/CD 流水线合并到 master 后首次运行
**状态**: 已修复

## 问题描述

CI workflow（`.github/workflows/ci.yml`）的 `Ruff 检查` 步骤失败，报 5 个 UP042 错误：

```
UP042 Class TaskStatus inherits from both `str` and `enum.Enum`
  --> app/models.py:22:7
```

涉及 `app/models.py` 中 5 个枚举类：
- `TaskStatus`（第 22 行）
- `TaskItemStatus`（第 32 行）
- `SourceType`（第 42 行）
- `VideoType`（第 51 行）
- `CookieStatus`（第 59 行）

均为 `class XxxStatus(str, Enum):` 形式。

## 根因分析

### 1. UP042 是 preview 规则

`UP042`（`replace-str-enum`）源自 pyupgrade linter，**当前仍是 preview 规则**，默认不启用：

```bash
$ ruff rule UP042
This rule is in preview and is not stable. The `--preview` flag is required for use.
```

本地 `ruff 0.12.0` 默认不报此错误，但 CI 环境的 ruff 版本更新或环境差异导致该规则被触发。

### 2. 本地无法复现

- 本地 ruff 版本：`0.12.0`（已升级到最新）
- 本地 `ruff check app/models.py`：`All checks passed!`
- 本地 `ruff check app/models.py --preview`：复现 5 个 UP042 错误

### 3. 行为变更背景（为什么这个规则有意义）

Python 3.11 引入了 `enum.StrEnum`，同时改变了 `str` + `Enum` 的格式化行为：

```python
class Foo(str, Enum):
    BAR = "bar"

# Python 3.10
f"{Foo.BAR}"  # > "bar"

# Python 3.11+
f"{Foo.BAR}"  # > "Foo.BAR"  ← 行为变更！
```

迁移到 `StrEnum` 可恢复旧行为（`f"{Foo.BAR}"` -> `"bar"`）。

项目 `pyproject.toml` 要求 `requires-python = ">=3.11"`，且 CI 用 Python 3.11，因此 `StrEnum` 可用。

## 修复方案

将 `app/models.py` 中 5 个 `class Xxx(str, Enum):` 改为 `class Xxx(StrEnum):`：

```python
# 修改前
from enum import Enum

class TaskStatus(str, Enum):
    ...

# 修改后
from enum import StrEnum

class TaskStatus(StrEnum):
    ...
```

### 行为影响评估

- `StrEnum` 继承自 `str`，所有 `.value` 比较与 SQLite 序列化行为不变
- `StrEnum` 恢复了 Python 3.11 之前 `f"{enum_member}"` -> `"value"` 的行为
- 项目中枚举主要用于状态字符串常量，无依赖 `f"{Foo.BAR}"` -> `"Foo.BAR"` 新行为的代码
- **风险**: 极低，迁移后行为更符合预期

## 验证

修复后本地验证：
- `ruff check .`（含 `--preview`）: 通过
- `black --check .`: 通过
- `pytest tests/ --ignore=tests/test_e2e`: 770 passed, 覆盖率 94%

## 后续建议

1. **考虑在 `pyproject.toml` 显式配置 preview 规则**：若希望 CI 与本地行为一致，可显式启用或禁用 preview，避免版本差异导致的规则漂移
2. **本地 ruff 版本对齐**：建议本地与 CI 保持相同 ruff 版本，可在 `requirements-dev.txt` 中固定版本（如 `ruff==0.12.0`）
