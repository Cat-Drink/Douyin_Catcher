## 三、偏差记录

### P3 偏差：cleanup_cookie_traces 保持禁用

- **plan 5.4 要求**：恢复 `cleanup_cookie_traces` fixture 的清理逻辑（删除 5 个 .test_*.txt 文件）
- **实际**：保持注释禁用状态
- **原因**：用户明确要求保留 .test_*.txt 文件以便多次运行集成测试；恢复清理会删除含真实 Cookie 的文件
- **影响**：测试后 Cookie 痕迹未自动清除；需用户手动清理或接受文件保留
- **决策依据**：AskUserQuestion 用户选择"保持禁用（推荐）"

### P3 偏差：ruff UP042 既存警告

- **plan 6.1 要求**：`ruff check .` 退出码 0
- **实际**：5 个 UP042 警告（[app/models.py](file:///d:/Program/Douyin_Catcher/app/models.py) 第 22/32/42/51/59 行 `class X(str, Enum):` 建议改为 `class X(StrEnum):`）
- **性质**：既存问题，非 v0.1.8 引入；ruff 标记为 unsafe fix（`--unsafe-fixes` 才可修复）
- **影响**：不影响功能与测试；UP042 是 pyupgrade 现代化建议，`str, Enum` 在 Python 3.11 仍完全可用
- **决策**：不在 v0.1.8 修复（非本里程碑范围，且为 unsafe fix）；建议后续里程碑统一处理

### P3 偏差：覆盖率较基线微降

- **plan 4.2 要求**：维持 v0.1.0 的 96.69% 基线
- **实际**：94.06%（较 v0.1.7 的 94.35% 微降 0.29%）
- **原因**：新增 e2e 文件含未运行代码（需真实 Cookie 才执行）；test_version_consistency.py 读取文件的分支未完全覆盖
- **影响**：仍远超 80% 达标线；未覆盖分支均在 e2e/资源读取路径，非核心业务逻辑
- **决策**：接受当前覆盖率；待真实环境运行集成测试后覆盖率将回升
