## 4. 设计依据与技术约束

### 4.1 图文流程依据（用户反馈 #7）

用户反馈明确要求："图文类型应当提供对应的下载选择，即抓取的时候就先把图片和视频抓取给用户进行选择，用户选中后再进行下载，包括像标题，封面这些也是，先把数据抓取给用户看"。

### 4.2 流程变更

**当前流程**（v0.1.6）：
```
用户输入链接 -> 解析 -> 直接入队下载（全量下载）
```

**新流程**（v0.1.7）：
```
用户输入链接 -> 解析 -> 抓取预览数据（标题/封面/图片列表/视频信息）
                            ↓
                   展示预览给用户选择
                            ↓
                   用户勾选 -> 入队下载（仅勾选项）
```

### 4.3 预览数据结构

新增 `PreviewItem` dataclass：
```python
@dataclass
class PreviewItem:
    aweme_id: str
    title: str
    cover_url: str
    type: str  # "video" / "image_set" / "long_video"
    duration: int
    image_urls: list[str]  # 图集类型非空，视频类型为空
    video_url: str  # 视频类型非空，图集类型为空
    author: str
```

### 4.4 DB schema 变更

`task_items` 表新增字段：
```sql
ALTER TABLE task_items ADD COLUMN selected_image_indices TEXT DEFAULT '';
-- JSON 数组，如 "[0,1,3]" 表示勾选第 0、1、3 张图片；空字符串表示全选
```

### 4.5 图片直链时效性处理

预览阶段获取的 `image_urls` 可能有时效性，下载前处理策略：
- **入队时**：将 `image_urls` 与 `selected_image_indices` 一起写入 `TaskItem`
- **下载时**：若 `image_urls` 失效（HTTP 403/404），调用 `VideoParser.parse(aweme_id)` 重新获取 `image_urls`，按 `selected_image_indices` 筛选后下载
- **重新解析失败**：标记任务失败，提示"图片链接失效，请重新解析"

### 4.6 图集任务行进度

图集任务行进度显示规则：
- `total_bytes` 改为 `total_images`（图集类型）
- `downloaded_bytes` 改为 `downloaded_images`（图集类型）
- 进度文字显示"已下载 M/N 张"（M=downloaded_images，N=total_images）
- 进度条仍按比例显示（M/N * 100%）

```python
async def parse_for_preview(self, text: str) -> None:
    """解析链接为预览数据，展示给用户选择。
    
    Args:
        text: 用户输入的链接文本（可能含分享文本）
    """
    try:
        parsed_urls = self._url_parser.parse(text)
        preview_items = []
        for parsed in parsed_urls:
            video_info = await self._video_parser.parse(parsed.aweme_id, self._get_cookie())
            preview_item = PreviewItem(
                aweme_id=video_info.aweme_id,
                title=video_info.title,
                cover_url=video_info.cover_url,
                type=video_info.type,
                duration=video_info.duration,
                image_urls=video_info.image_urls,
                video_url=video_info.no_watermark_url,
                author=video_info.author,
            )
            preview_items.append(preview_item)
        self._signals.preview_completed.emit(preview_items)
    except Exception as e:
        self._signals.preview_failed.emit(str(e))
```

#### 6.5 图集下载逻辑

`Downloader` 下载图集时：

2. 若为空字符串，表示全选，下载所有 `image_urls`

#### 6.6 图片直链失效处理

```python
async def _download_image_set(self, task_item: TaskItem) -> None:
    """下载图集，处理图片直链时效性。"""
    image_urls = task_item.image_urls  # 从 DB 读取
    selected_indices = json.loads(task_item.selected_image_indices) if task_item.selected_image_indices else None
    
    if selected_indices is not None:
        image_urls = [image_urls[i] for i in selected_indices]
    
    # 尝试下载
    for i, url in enumerate(image_urls):
        try:
            await self._download_single(url, ...)
        except HTTPError as e:
            if e.status_code in (403, 404):
                # 图片直链失效，重新解析
                video_info = await self._video_parser.parse(task_item.aweme_id, self._get_cookie())
                new_urls = video_info.image_urls
                if selected_indices is not None:
                    new_urls = [new_urls[i] for i in selected_indices]
                await self._download_single(new_urls[i], ...)
            else:
                raise
```

## 8. 风险与注意事项

### 8.1 技术风险

| 风险 | 影响 | 缓解措施 |
|---|---|---|
| 预览数据量大（图集 30+ 张图片） | 预览阶段耗时长 | loading 状态 + 超时处理；缩略图异步加载 |
| 图片直链时效性 | 下载阶段直链失效 | 下载前校验，失效时重新解析；重新解析失败标记任务失败 |
| DB schema 变更影响已有任务 | 已有任务记录字段为空 | DEFAULT '' 表示全选；UI 显示进度时处理空值 |
| PreviewItemWidget 布局复杂 | UI 性能问题 | 缩略图异步加载；展开/收起动画节制 |
| 图片级勾选与全选联动复杂 | 交互逻辑混乱 | 复用 v0.1.6 的全选逻辑，扩展到图片级；严格测试 |
| `parse_for_preview` 与 `parse_links` 并存 | 调用方混乱 | 文档明确两者用途；`parse_for_preview` 用于预览模式，`parse_links` 保留兼容 |

### 8.2 实现注意事项

1. **DB 迁移幂等**：`ALTER TABLE` 前检查列是否存在
2. **图片直链失效处理**：403/404 触发重新解析，其他错误直接标记失败
3. **图集进度显示**：`downloaded_images`/`total_images` 而非字节数
4. **PreviewItem 与 VideoInfo 区分**：PreviewItem 是预览阶段数据载体，VideoInfo 是解析阶段数据载体，两者字段相似但不完全相同
5. **预览模式不破坏原流程**：`parse_links` 保留，`parse_for_preview` 新增，抓取页改用 `parse_for_preview`
6. **图集展开性能**：大量图片缩略图加载需复用 `thumbnail_loader.py`，避免重复请求
7. **图片级勾选状态持久化**：`selected_image_indices` 用 JSON 数组存储，空字符串表示全选
