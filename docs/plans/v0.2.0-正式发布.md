## 8. 风险与注意事项

### 8.1 技术风险

| 风险 | 影响 | 缓解措施 |
|---|---|---|
| 干净 VM 缺少 Visual C++ 运行时 | 应用启动报 DLL 缺失 | PyInstaller 通常打包 VC 运行时；若缺失，Release Notes 提示安装 |
| GitHub Release 上传失败 | 发布延迟 | 网络问题重试；或手动上传 |
| Git push 失败 | 远端不同步 | 检查网络与权限；必要时 `git pull --rebase` 后重试 |
| 干净 VM 验证发现新 bug | 发布阻塞 | 修复后重新打包；或列为已知限制发布 |
| Cookie 痕迹清除不彻底 | 敏感信息泄露 | 多轮 grep 扫描；gitleaks 工具辅助 |

### 8.2 实现注意事项

1. **版本号最终同步**：v0.2.0 是最终发布版本，三处版本号必须一致
2. **干净 VM 环境严格**：VM 必须无 Python、无历史版本，模拟真实用户环境
3. **Cookie 清除彻底**：所有 `.test_*.txt` 文件内容清空，临时数据库删除
4. **Git tag 不可变**：tag 发布后不可更改，需确保版本号正确
5. **GitHub Release 描述**：完整复制 Release Notes 内容，含新功能、已知限制、升级说明
6. **仓库推送完整**：v0.1.0 后累积的所有 commit 与 tag 都需推送到远端
