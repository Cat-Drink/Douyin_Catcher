## 4. 设计依据与技术约束

### 4.1 全选联动依据（用户反馈 #4）

用户反馈明确要求："如果已经单独选完了列表的全部东西，那就默认为选中了全选"。

### 4.2 提交清理依据（用户反馈 #6）

用户反馈明确要求："选中要下载的链接并提交任务到下载窗口后，抓取窗口就不要再显示对应的内容了，避免造成干扰"。

### 4.3 三态复选框技术约束

PySide6 `QCheckBox` 支持三态：
- `Qt.Unchecked`：未选（0 项勾选）
- `Qt.PartiallyChecked`：部分选（1~N-1 项勾选）
- `Qt.Checked`：全选（N 项勾选）

需调用 `setTristate(True)` 启用三态。

### 4.4 提交清理时机约束

清理必须在 Bridge 确认入队成功后执行：
- Bridge 发出 `download_started` 信号 -> 触发清理
- 若 Bridge 发出 `download_failed` 信号 -> 不清理，保留内容供用户重试

### 任务 1：全选联动逻辑

#### 1.1 目标

当用户手动逐个勾选全部结果项时，自动同步"全选"复选框状态为已勾选；取消任一项时自动取消"全选"复选框。

#### 1.2 文件清单

| 文件 | 类型 | 说明 |
|---|---|---|
| `ui/pages/fetch_page.py` | 修改 | ResultItemWidget 勾选信号连接 + 全选同步逻辑 |

#### 1.3 实现要点

**启用三态**：
```python
self._select_all_chk.setTristate(True)
```

**ResultItemWidget 勾选信号连接**：
```python
def _on_item_check_changed(self, item: ResultItemWidget, state: int) -> None:
    """单个结果项勾选状态变化时，同步全选复选框。"""
    selected_count = sum(1 for w in self._result_widgets if w.is_selected())
    total_count = len(self._result_widgets)
    
    if selected_count == 0:
        self._select_all_chk.setCheckState(Qt.Unchecked)
    elif selected_count == total_count:
        self._select_all_chk.setCheckState(Qt.Checked)
    else:
        self._select_all_chk.setCheckState(Qt.PartiallyChecked)
    
    self._update_selected_count()
```

**全选复选框点击处理**：
```python
def _on_select_all_changed(self, state: int) -> None:
    """全选复选框状态变化时，同步所有结果项。"""
    if state == Qt.PartiallyChecked:
        return  # 部分选状态不响应点击（避免循环）
    
    selected = (state == Qt.Checked)
    for widget in self._result_widgets:
        widget.set_selected(selected)
    self._update_selected_count()
```

**防止循环触发**：
- 全选复选框的 `stateChanged` 信号触发时，需先断开 ResultItemWidget 的信号，同步完成后再连接
- 或使用标志位 `_syncing_select_all` 防止递归

#### 1.4 验证点

- 手动勾选全部 N 项时，全选复选框自动变为已勾选
- 取消任一项时，全选复选框自动变为部分选
- 取消全部项时，全选复选框自动变为未选
- 点击全选复选框能正确切换全部项勾选/取消
- 全选复选框部分选状态时不响应点击（或点击切换到全选/全不选）

### 任务 2：提交下载后清理

#### 2.1 目标

点击"开始下载"并成功入队后：清空输入框、清空结果列表、隐藏过滤栏、重置全选状态；Toast 提示"已加入下载队列"。

#### 2.2 文件清单

| 文件 | 类型 | 说明 |
|---|---|---|
| `ui/pages/fetch_page.py` | 修改 | 提交后清理逻辑 |
| `ui/widgets/toast.py` | 确认 | Toast 组件可用 |

#### 2.3 清理逻辑

**`_on_download_started()` 新增**：
```python
def _on_download_started(self) -> None:
    """Bridge 确认入队成功后，清理抓取页。"""
    # 1. 清空输入框
    self._input_edit.clear()
    
    # 2. 清空结果列表
    self._clear_result_list()
    
    # 3. 隐藏过滤栏
    self._filter_bar.hide()
    self._home_hint_label.hide()
    
    # 4. 重置全选状态
    self._select_all_chk.setCheckState(Qt.Unchecked)
    
    # 5. 重置已选计数
    self._update_selected_count()
    
    # 6. Toast 提示
    Toast.show("已加入下载队列", parent=self)
```

**`_clear_result_list()` 新增**：
```python
def _clear_result_list(self) -> None:
    """清空结果列表，删除所有 ResultItemWidget。"""
    for widget in self._result_widgets:
        self._list_layout.removeWidget(widget)
        widget.deleteLater()
    self._result_widgets.clear()
    self._show_empty_state(True)  # 显示空状态
```

#### 2.4 Bridge 信号连接

**确认 Bridge 发出入队成功信号**：
- 若 v0.0.6 已有 `download_started` 信号，直接连接到 `_on_download_started`
- 若无，需在 `worker/download_bridge.py` 中补充 `download_started` 信号，在 `start_download()` 成功后发出

**信号连接**：
```python
self._bridge.download_started.connect(self._on_download_started)
self._bridge.download_failed.connect(self._on_download_failed)
```

**失败处理**：
```python
def _on_download_failed(self, reason: str) -> None:
    """入队失败，不清理，保留内容供用户重试。"""
    Toast.show(f"下载失败：{reason}", parent=self, error=True)
```

#### 2.5 验证点

- 点击"开始下载"成功后，输入框清空
- 结果列表清空，显示空状态
- 过滤栏隐藏
- 全选状态重置为未选
- Toast "已加入下载队列"显示
- 入队失败时不清理，Toast 显示失败原因

def _on_parse_cancelled(self) -> None:
    """用户取消解析时，保留输入文本，清空部分结果。"""
    # 1. 保留输入框文本（不清空）
    # 2. 清空已解析的部分结果

## 8. 风险与注意事项

### 8.1 技术风险

| 风险 | 影响 | 缓解措施 |
|---|---|---|
| 全选联动循环触发 | 递归导致栈溢出 | 使用标志位 `_syncing_select_all` 防止递归；或断开信号后同步再连接 |
| 三态复选框 QSS 样式冲突 | 部分选状态显示异常 | 确认 QSS 支持 `QCheckBox:indeterminate` 样式 |
| Bridge 未发出 `download_started` 信号 | 清理逻辑不触发 | 确认 `worker/download_bridge.py` 发出信号；若无则补充 |
| 提前清理导致任务丢失 | 用户提交后任务未入队 | 严格在 `download_started` 信号后清理，失败时不清理 |
| Toast 组件不支持 error 样式 | 失败提示不明显 | 确认 `Toast.show()` 支持 error 参数；若无则补充 |

### 8.2 实现注意事项

1. **三态复选框启用**：`setTristate(True)` 必须在初始化时调用
2. **部分选状态不响应点击**：`_on_select_all_changed` 中 `if state == Qt.PartiallyChecked: return`，避免循环
3. **清理时机严格**：`download_started` 信号后清理，`download_failed` 信号后保留
4. **Toast 位置**：Toast 显示在抓取页内，不遮挡其他区域
5. **空状态切换**：清理后显示空状态，有结果时隐藏空状态
