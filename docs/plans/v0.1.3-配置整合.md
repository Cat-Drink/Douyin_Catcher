## 2. 里程碑概述

### 2.1 里程碑定位

本里程碑是 v0.1.2 后的第三个迭代，聚焦配置整合：将下载目录配置统一至设置页，长视频定义从文件大小改为时长（≥30 分钟）。两项改动为后续 v0.1.5 链接解析增强（类型标记）与 v0.1.7 图文流程提供基础。

```
里程碑序列：
  v0.1.2 下载页布局重构           ✅ 前置依赖（已完成）
  v0.1.3 配置整合                 ◄── 本里程碑
  v0.1.4 下载页信息展示           ◄── 后续
  ...
```

### 2.2 前置依赖

| 依赖项 | 来源 | 说明 |
|---|---|---|
| v0.1.2 完成 | 上一里程碑 | 抓取页布局已重构，开始下载按钮已移位 |
| `ui/pages/fetch_page.py` | v0.1.2 | 抓取页底部操作栏仅保留下载目录显示与浏览按钮 |
| `ui/pages/settings_page.py` | v0.0.8 | 设置页已有下载目录配置项 |
| `crawlers/video_parser.py` | v0.0.4 | `VideoParser.parse()` 返回 `type` 字段 |
| `downloader/downloader.py` | v0.0.5 | 含 `LARGE_FILE_THRESHOLD` 常量 |

**关键约束**：长视频定义改动会影响 v0.1.0 已有测试用例，需同步更新断言。

### 2.3 交付目标

## 3. 目标与范围

### 3.1 本里程碑包含

| 模块 | 文件 | 职责 |
|---|---|---|
| 抓取页 | `ui/pages/fetch_page.py` | 移除下载目录输入框与浏览按钮 |
| 下载引擎常量 | `downloader/constants.py`（新建）或 `downloader/downloader.py` | 新增 `LONG_VIDEO_DURATION_THRESHOLD` 常量 |
| 视频解析 | `crawlers/video_parser.py` | 类型判定改为按时长 |
| 单元测试 | `tests/test_video_parser.py` 等 | 同步更新断言 |

### 3.2 本里程碑不包含

- 设置页下载目录配置项新增（v0.0.8 已实现）
- 业务逻辑大改动
- 新增功能

### 3.3 范围边界

- 长视频阈值改动**仅影响类型判定**，不影响下载引擎的分片逻辑（分片仍按 `LARGE_FILE_THRESHOLD` 10MB 触发）
- 抓取页下载目录移除后，下载任务从设置页读取 `ConfigRepository.get("download_dir")`
- 若设置页 `download_dir` 为空，下载入队时报错提示"请先在设置页配置下载目录"

## 4. 设计依据与技术约束

### 4.1 下载目录配置依据（用户反馈 #9）

用户反馈明确要求："下载目录的配置应当只能在设置中进行改动，应当移除抓取页的下载目录显示和选择"。

### 4.2 长视频定义依据（用户反馈 #12）

用户反馈明确要求："长视频的定义修改一下，只有超过30分钟的才叫长视频"。

### 4.3 配置统一原则（设计文档 8.2 节）

设计文档第 8.2 节分层职责边界规定 UI 通过 Bridge 调用业务逻辑。下载目录属配置项，应统一在设置页管理，抓取页不应有独立的配置入口。

### 4.4 长视频阈值单一来源

为避免阈值散落，本里程碑新增 `LONG_VIDEO_DURATION_THRESHOLD = 1800` 常量，定义在 `downloader/constants.py`（新建）或 `downloader/downloader.py` 顶部。`crawlers/video_parser.py` 从其导入。

### 任务 2：长视频阈值常量化

#### 2.1 目标

新增 `LONG_VIDEO_DURATION_THRESHOLD = 1800`（30 分钟，秒）常量，为长视频类型判定提供单一来源。

#### 2.2 文件清单

| 文件 | 类型 | 说明 |
|---|---|---|

#### 2.3 constants.py 内容

```python
"""下载引擎常量集中定义。"""

# 长视频时长阈值（秒），超过此值判定为 long_video 类型
LONG_VIDEO_DURATION_THRESHOLD: int = 1800

# 大文件阈值（字节），超过此值触发分片下载
LARGE_FILE_THRESHOLD: int = 10 * 1024 * 1024  # 10MB

# 分片大小（字节）
SEGMENT_SIZE: int = 2 * 1024 * 1024  # 2MB

# 最大分片数
MAX_SEGMENTS: int = 8
```

#### 2.4 验证点

- `from downloader import LONG_VIDEO_DURATION_THRESHOLD` 可正常导入

### 任务 3：长视频判定改为按时长

#### 3.1 目标

`VideoParser.parse()` 返回的 `VideoInfo.type` 字段判定从按文件大小改为按时长，`duration >= 1800` 则 `type='long_video'`。

#### 3.2 文件清单

| 文件 | 类型 | 说明 |
|---|---|---|
| `crawlers/video_parser.py` | 修改 | 类型判定逻辑更新 |

#### 3.3 判定逻辑

**当前逻辑**（v0.1.0，按文件大小）：
```python
if file_size >= LARGE_FILE_THRESHOLD:
    video_type = "long_video"
elif image_count > 0:
    video_type = "image_set"
else:
    video_type = "video"
```

**目标逻辑**（v0.1.3，按时长）：
```python
from downloader.constants import LONG_VIDEO_DURATION_THRESHOLD

if image_count > 0:
    video_type = "image_set"
elif duration >= LONG_VIDEO_DURATION_THRESHOLD:
    video_type = "long_video"
else:
    video_type = "video"
```

**关键变更**：
- 图集判定优先（`image_count > 0` 先判定）
- 长视频判定从文件大小改为时长
- `LARGE_FILE_THRESHOLD` 不再用于类型判定，仅用于下载引擎分片触发

#### 3.4 验证点

- 31 分钟视频（1860 秒）标记为 `long_video`
- 30 分钟视频（1800 秒）标记为 `long_video`（`>=` 阈值）
- 29 分钟视频（1740 秒）标记为 `video`
- 图集（多图）仍标记为 `image_set`
- 文件大小不再影响类型判定

## 8. 风险与注意事项

### 8.1 技术风险

| 风险 | 影响 | 缓解措施 |
|---|---|---|
| 长视频阈值改动影响 v0.1.0 集成测试 | `test_long_video.py` 断言失败 | 同步更新集成测试断言；若测试视频时长不明确，需用真实视频验证 |
| 抓取页移除下载目录后用户不知道去哪配置 | 用户困惑 | 在原位置显示提示"下载目录请在设置页配置"；或首次使用时引导 |
| `download_dir` 为空时下载失败提示不够明显 | 用户重复尝试 | Toast 提示 + 跳转设置页按钮 |
| `downloader/constants.py` 新建文件未被打包 | PyInstaller 漏打包 | v0.1.9 打包时确认 `hiddenimports` 包含 `downloader.constants` |

### 8.2 实现注意事项

1. **图集判定优先**：`image_count > 0` 先判定，避免图集被误判为长视频（图集也可能有时长字段）
2. **阈值边界**：`>=` 表示 30 分钟整也算长视频，需在测试中明确验证
3. **常量导入方向**：`crawlers/` 从 `downloader/` 导入常量，符合"爬虫层依赖下载引擎层"的分层方向（下载引擎提供基础常量，爬虫层使用）
4. **下载目录读取时机**：Bridge 在 `start_download` 时读取，而非入队时读取，避免用户在入队后修改目录导致不一致
