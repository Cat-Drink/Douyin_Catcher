## 4. 设计依据与技术约束

### 4.1 标题栏移除依据（设计文档 3.2 节）

设计文档第 3.2 节视觉风格规定"简洁现代扁平化"，但当前 v0.1.0 主窗口保留了系统标题栏文字（"抖音抓取器"），与扁平化风格不一致。用户反馈明确要求移除非客户区标题栏。

### 4.2 侧边栏样式依据（UIUX 规范 4.2 节）

UIUX 规范第 4.2 节按钮规范未定义选中态蓝色描边，当前 v0.1.0 的 QSS 中侧边栏按钮选中态存在 `outline: 2px solid #0078D7`（Windows 默认焦点色），属样式残留，需移除。

### 4.3 版本号规范依据（规范文档 8.3 节）

规范文档第 8.3 节明确版本号需在以下位置同步：
- `pyproject.toml` 的 `version` 字段
- `installer.iss` 的 `AppVersion` 字段
- 应用"关于"页面显示
- Git tag

### 4.4 版本号单一来源原则

为避免后续版本号漂移，本里程碑抽取单一常量 `_APP_VERSION` 供 UI 引用：
- `ui/main_window.py` 顶部定义 `_APP_VERSION = "0.1.1"`
- 关于页 `SettingsPage` 通过 `from ui.main_window import _APP_VERSION` 引用
- `pyproject.toml` 与 `installer.iss` 因属不同工具链，仍需手动同步

### 任务 1：移除非客户区标题栏

#### 1.1 目标

移除主窗口标题栏文字（"抖音抓取器"），保留窗口拖动、最小化/最大化/关闭按钮功能。

#### 1.2 文件清单

| 文件 | 类型 | 说明 |
|---|---|---|
| `ui/main_window.py` | 修改 | 移除标题栏文字或改为无边框窗口 |

#### 1.3 实现方案

**方案选择**：保留系统标题栏但隐藏标题文字（低风险），不使用 `Qt.FramelessWindowHint`（高风险，需自绘所有按钮）。

**关键步骤**：
1. 在 Windows 上通过 Win32 API 设置窗口标题栏文字为空字符串
2. 或重写 `setWindowTitle("")` 并确保 QSS 不显示标题文字
3. 保留系统提供的最小化/最大化/关闭按钮
4. 保留窗口拖动功能（系统标题栏拖动）

#### 1.4 验证点

- 窗口标题栏无"抖音抓取器"文字
- 最小化按钮可用
- 最大化/还原按钮可用
- 关闭按钮可用
- 标题栏可拖动窗口

---

### 任务 2：修复侧边栏选中态蓝边框

#### 2.1 目标

移除侧边栏导航按钮选中态的蓝色描边，仅保留底色变化作为选中反馈。

#### 2.2 文件清单

| 文件 | 类型 | 说明 |
|---|---|---|
| `ui/widgets/nav_bar.py` | 修改 | 确认选中态样式应用方式（setProperty + polish） |
| `ui/assets/style.qss` | 修改 | 移除侧边栏按钮选中态 `outline`/`border` 蓝色描边 |

#### 2.3 QSS 修改

**当前问题样式**（待移除）：
```css
/* 侧边栏按钮选中态 */
NavBarButton:checked,
NavBarButton[selected="true"] {
    outline: 2px solid #0078D7;  /* 移除 */
    /* 或 */
    border: 2px solid #0078D7;   /* 移除 */
}
```

**目标样式**：
```css
NavBarButton:checked,
NavBarButton[selected="true"] {
    background-color: #F3F4F6;  /* 仅保留底色变化 */
    color: #7C3AED;             /* 品牌紫文字 */
    /* 无 outline，无 border */
}

NavBarButton:focus {
    outline: none;  /* 移除焦点描边 */
}
```

#### 2.4 验证点

- 侧边栏切换页面时无任何蓝色描边出现
- 选中态仍有视觉反馈（底色变化 + 品牌紫文字）
- 截屏比对：选中按钮与未选中按钮的视觉差异仅底色与文字色

## 8. 风险与注意事项

### 8.1 技术风险

| 风险 | 影响 | 缓解措施 |
|---|---|---|
| 移除标题栏文字方式不当导致窗口无法拖动 | 用户体验严重下降 | 优先采用"保留系统标题栏仅隐藏文字"方案；若必须用 `FramelessWindowHint`，需自绘标题栏并实现拖动 |
| Win32 API 设置标题栏文字在打包后失效 | 打包版本仍有文字 | 在 v0.1.9 打包阶段验证；若失效，回退到 `setWindowTitle("")` |
| QSS 修改影响其他按钮样式 | 其他按钮选中态异常 | 修改后全量回归测试所有按钮选中态 |
| 版本号常量抽取导致循环导入 | 应用启动报错 | `_APP_VERSION` 定义在 `ui/main_window.py` 顶部，`settings_page.py` 从其导入，无循环依赖 |

### 8.2 实现注意事项

1. **标题栏移除方案选择**：优先低风险方案（保留系统标题栏仅隐藏文字），避免 `FramelessWindowHint` 带来的按钮自绘工作量
2. **QSS 状态切换**：移除 `outline`/`border` 后，确保 `setProperty("selected", True)` + `style().unpolish()`/`polish()` 仍能正确切换底色
3. **版本号常量命名**：使用下划线前缀 `_APP_VERSION` 表示模块内部常量，避免被外部误用
4. **Release Notes 日期**：发布日期待 v0.1.9 打包阶段确定，本里程碑先填占位
