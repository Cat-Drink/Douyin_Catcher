## 8. 风险与注意事项

### 8.1 技术风险

| 风险 | 影响 | 缓解措施 |
|---|---|---|
| `icon.ico` 与教程截图未提供 | 打包阻塞 | 生成占位图；或用户延迟提供，先打包不含截图版本 |
| PyInstaller 漏打包新增模块 | 启动报 ModuleNotFoundError | `hiddenimports` 显式声明 `downloader.constants`、`app.preview_models` |
| 安装包体积超出 80MB | 用户体验差 | 审查 excludes；启用 UPX 压缩 |
| Inno Setup 中文语言包缺失 | 安装向导显示英文 | 确认 Inno Setup 安装时勾选 Chinese Simplified |
| 打包后 QSS 样式异常 | UI 显示异常 | 确认 `ui/assets/style.qss` 打包路径正确 |
| 打包后教程截图不显示 | Cookie 教程空白 | 确认 `ui/assets/cookie_tutorial/` 打包路径正确 |

### 8.2 实现注意事项

1. **资源路径**：打包后资源位于 `sys._MEIPASS`（onedir 模式为 `_internal`），代码中需正确解析
2. **版本号一致**：三处版本号必须同步，避免用户混淆
3. **用户数据保留**：`[UninstallDelete]` 仅清理 `{app}`，不清理 `%APPDATA%`
4. **安装包体积**：超出 100MB 需审查依赖，用 UPX 压缩
5. **新功能验证重点**：v0.1.7 图文勾选下载流程在打包后需重点验证
