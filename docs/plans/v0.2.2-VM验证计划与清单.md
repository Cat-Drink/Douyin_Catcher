## 4. 验证执行说明

### 4.1 VM 环境准备

1. 宿主机安装 VirtualBox 7.2.14（路径：`D:\Virtual`）
2. 下载 Win10/Win11 评估 VM 到 `D:\VM\`
3. 导入 .ova 到 VirtualBox
4. 设置网络为 NAT 模式
5. 启动 VM，确认网络正常

### 4.2 安装包传输

- 宿主机打包生成 `dist/DouyinCatcher_Setup_v0.2.2.exe`
- 通过共享文件夹或 U 盘复制到 VM

### 4.3 验证注意事项

- 优先验证核心功能（#1-#14），再验证引导流程
- 卸载测试最后执行（卸载后无法恢复）
- 每条失败项需记录详细错误信息
