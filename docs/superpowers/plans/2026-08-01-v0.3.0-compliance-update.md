# v0.3.0 Compliance Update Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 修正 v0.3.0 的项目归属信息，补充上游参考和第三方许可证审计材料，并为关键合规约束建立可重复的回归检查。

**Architecture:** 采用纯文档、标准库审计脚本和 pytest 静态回归测试，不改变爬虫、签名、下载运行时逻辑。许可证报告脚本分别解析 Python 直接依赖、npm lockfile 和 Cargo.lock，把自动发现与待人工核验项分开。

**Tech Stack:** Python 3.11 标准库、pytest、Markdown、Git。

## Global Constraints

- 不修改爬取、签名、解析、下载运行时行为。
- 不引入新的运行时依赖。
- 不推送分支、不创建 PR。
- 每个主题独立提交，提交前运行 `git diff --check`。
- 不把未经核实的第三方代码、测试向量或许可证标为本项目自有内容。
