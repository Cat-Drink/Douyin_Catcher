# 抖音抓取器 v0.2.0

发布日期：2026-07-19

v0.2.0 是 v0.1.1~v0.2.0 共 10 个迭代里程碑的收官版本，标志本轮 14 项需求的完整交付。本版本完成首次正式打包发布，提供 Windows 安装包，覆盖 UI 优化、图文下载流程、长视频识别、版本号一致性等核心改进。

## 新功能

| 编号 | 功能 | 说明 |
|---|---|---|
| 1 | 分享文本短链接自动提取 | 输入完整分享文本即可自动提取短链接，无需手动剥离前后文字 |
| 2 | 下载任务页显示视频标题 | 任务行展示视频标题（超长自动省略号），失败时回退到短链接 |
| 3 | 任务行缩略图改用视频封面 | 缩略图采用视频封面图，视觉识别更直观 |
| 4 | 抓取页全选联动（三态复选框） | 全选支持"全选/部分选/未选"三态联动，避免反复手动勾选 |
| 5 | 侧边栏选中态蓝边框移除 | 移除导航按钮获得焦点时的蓝色描边，仅保留底色与品牌紫文字反馈 |
| 6 | 抓取页提交后自动清理 | 提交下载后清空部分结果、重置选择、隐藏筛选栏，并保留输入文本便于复用 |
| 7 | 图文类型预览勾选下载 | 图文链接支持预览后勾选下载，预览页支持缩略图与选中态 |
| 8 | 抓取结果类型标签显示 | 解析结果列表展示视频/图文/长视频类型标签，便于分类筛选 |
| 9 | 下载目录统一至设置页 | 移除抓取页下载目录控件，统一在设置页管理，避免配置漂移 |
| 10 | 开始下载按钮位置调整 | 开始下载按钮移至抓取页操作行，符合主操作视觉焦点 |
| 11 | 版本号三处同步 | `pyproject.toml` / `installer.iss` / `ui/main_window.py` 三处版本号保持一致 |
| 12 | 长视频定义改为 ≥30 分钟 | 长视频判定由文件大小改为时长阈值（≥30 分钟），更符合实际语义 |
| 13 | 移除非客户区标题栏 | 移除主窗口非客户区标题栏文字，视觉更简洁 |
| 14 | 底部状态栏固定至侧边栏 | 移除 `QMainWindow` 状态栏，状态信息固定显示在侧边栏底部，避免与页面内容冲突 |

## 已知限制

- 仅支持 Windows 10/11 x64 系统
- 不会自动通过抖音验证（如滑块验证码），遇到验证时任务会标记为失败并提示用户
- Cookie 需用户自行维护（在设置页配置），不做自动登录
- 签名算法（X-Bogus / msToken）可能随抖音服务端更新失效，失效后需更新算法
- 首次启动引导流程需要用户手动配置下载目录与 Cookie

### 系统要求

- Windows 10 1809+ / Windows 11 x64
- Visual C++ 2015-2022 Redistributable（PyInstaller 通常已内嵌；若启动报 DLL 缺失请从微软官网安装）
- 磁盘空间 ≥ 200 MB（安装目录 + 用户数据）

## 升级说明

- 相对 v0.1.0：直接覆盖安装，用户数据（`%APPDATA%/DouyinCatcher/`）自动保留
- 卸载仅清理安装目录（`%ProgramFiles%/DouyinCatcher/`），不会清理用户数据
- 升级后首次启动时，如已存在历史用户数据，将自动复用既有下载目录与 Cookie 配置
