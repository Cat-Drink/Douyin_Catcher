## 打包执行步骤

### 1. PyInstaller 打包

```powershell
pip install pyinstaller
pyinstaller DouyinCatcher.spec --noconfirm
```

### 2. Inno Setup 安装包生成

```powershell
"%ProgramFiles(x86)%\Inno Setup 6\ISCC.exe" installer.iss
```

### 3. 端到端集成测试（需真实 Cookie）

```powershell
# 在项目根目录创建 .test_cookie.txt，写入有效抖音 Cookie
# 可选：创建 .test_aweme_id.txt、.test_sec_user_id.txt、.test_image_set_aweme_id.txt
pytest -m integration
```

### 4. 性能测试

```powershell
pytest -m slow
```
