# 抖音抓取器 v0.1.1

发布日期：2026-07-XX（待 v0.1.9 打包阶段确定）

## 新功能

- **移除主窗口标题栏文字**：采用"保留系统标题栏仅隐藏文字"方案，视觉更简洁，同时保留窗口拖动与最小化/最大化/关闭按钮功能
- **修复侧边栏选中态蓝色边框**：移除导航按钮获得焦点时的蓝色描边（`outline`），仅保留底色与品牌紫文字作为选中反馈，符合 UI/UX 规范 4.2 节
- **版本号统一管理**：抽取 `_APP_VERSION` 单一来源常量（定义于 `ui/main_window.py`），消除 `main_window` / `settings_page` / `nav_bar` 三处版本号漂移；同步 `pyproject.toml` 与 `installer.iss` 至 0.1.1

## 已知限制

- 本版本为开发迭代版本，尚未打包发布，需从源码运行
- 标题栏文字移除采用低风险方案（保留系统标题栏），未实现自绘无边框标题栏

## 升级说明

- 相对 v0.1.0 为纯 UI 微调，无业务逻辑改动
- 后续打包版本发布后，直接覆盖安装 v0.1.0，用户数据（`%APPDATA%/DouyinCatcher/`）自动保留

## 变更范围

| 文件 | 变更类型 | 说明 |
|---|---|---|
| `ui/main_window.py` | 修改 | 移除标题栏文字；新增 `_APP_VERSION` 单一来源常量 |

| `ui/pages/settings_page.py` | 修改 | 关于页版本号改为从 `_APP_VERSION` 引用，消除局部常量 |

| `installer.iss` | 修改 | `MyAppVersion` 与 `OutputBaseFilename` 同步至 0.1.1 |
| `tests/test_ui_smoke.py` | 修改 | 适配标题栏文字移除后的断言 |
