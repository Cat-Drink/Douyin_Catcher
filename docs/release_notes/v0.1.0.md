# 抖音抓取器 v0.1.0

发布日期：2026-07-13

## 新功能

- **单视频/图集/长视频下载**：支持抖音短视频、图文图集、长视频的无水印下载，自动识别内容类型
- **批量链接下载**：支持粘贴多个链接批量解析与下载，提高下载效率
- **用户主页批量抓取**：输入主页链接，抓取作品列表，勾选后批量下载
- **文件导入链接列表**：支持 txt 文件导入链接列表，批量解析下载（自动跳过空行与注释行）
- **断点续传（任务队列 + 单文件分块）**：下载中断后重启应用可恢复下载，单文件支持 HTTP Range 分块续传
- **多线程并发下载（可配 1-10）**：用户可配置并发下载数，默认 3，上限 10
- **失败自动重试（3 次，指数退避）**：网络错误/限流自动重试 3 次，指数退避（2s/4s/8s）
- **Cookie 池管理（单/多 Cookie 轮换）**：支持多 Cookie 轮换，失效自动切换，均衡负载
- **首次使用引导**：首次启动引导用户设置下载目录与配置 Cookie
- **图文 Cookie 教程**：内嵌图文步骤教程，指导用户获取抖音 Cookie

## 已知限制

- **仅支持 Windows**：当前版本仅支持 Windows 10/11 x64，不支持 macOS/Linux
- **不自动过抖音验证**：遇到滑块验证时标记失败，需用户更新 Cookie 后重试
- **Cookie 需用户自行维护**：应用不提供登录功能，Cookie 由用户从浏览器获取并配置
- **签名算法可能随抖音更新失效**：签名算法基于当前抖音 Web API 实现，抖音更新风控策略后可能失效，需更新算法

## 技术规格

- **Python 版本**：>=3.11
- **打包模式**：PyInstaller --onedir（启动快于 onefile）
- **安装包大小**：约 60-80MB
- **运行时数据位置**：`%APPDATA%/DouyinCatcher/`（与程序目录分离，卸载不丢失）
- **代码覆盖率**：96.75%（595 个单元测试 + 10 个端到端集成测试 + 4 个性能测试）

## 安全说明

- 应用不收集任何用户数据
- Cookie 仅存储在本地 `%APPDATA%/DouyinCatcher/data.db`，不上传任何服务器
- 下载文件保存在用户指定的下载目录
- 日志文件位于 `%APPDATA%/DouyinCatcher/logs/`，按天滚动保留 7 天
