## 五、打包执行步骤

### 1. PyInstaller 打包

```powershell
pyinstaller DouyinCatcher.spec --noconfirm
```

产物：`dist/DouyinCatcher/DouyinCatcher.exe`

### 2. Inno Setup 安装包生成

```powershell
& "$env:LOCALAPPDATA\Programs\Inno Setup 6\ISCC.exe" installer.iss
```

产物：`dist/DouyinCatcher_Setup_v0.1.9.exe`

### 3. 静默安装验证

```powershell
Start-Process -FilePath "dist/DouyinCatcher_Setup_v0.1.9.exe" -ArgumentList "/SILENT","/NORESTART","/SUPPRESSMSGBOXES" -Wait
```

### 4. 静默卸载验证

```powershell
Start-Process -FilePath "$env:ProgramFiles\DouyinCatcher\unins000.exe" -ArgumentList "/SILENT","/NORESTART","/SUPPRESSMSGBOXES" -Wait
```
