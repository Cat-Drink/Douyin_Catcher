## 2. 里程碑概述

### 2.1 里程碑定位

本里程碑负责把前端重构的“骨架”搭起来：设计系统先定，主窗口与页面布局先定，所有核心页面先用 mock 数据做成可交互原型。此阶段不追求业务联通，重点是把 UI 原型、外观与信息结构一次性定准。

### 2.2 前置依赖

| 依赖项 | 来源 | 说明 |
|---|---|---|
| 重构路线设计已确认 | `docs/superpowers/specs/2026-07-28-tauri-react-restructure-roadmap-design.md` | 新技术路线基准 |
| 现有 UI/UX 规范 | `docs/structure/06-UIUX-设计规范与高保真原型.md` | 设计语言参考 |
| React / Tauri 技术选型 | 项目决策 | 前端实现基础 |

### 2.3 交付目标

| 目标 | 衡量指标 |
|---|---|
| 前端脚手架可运行 | Tauri + React 启动成功 |
| 设计系统冻结 | 颜色、字体、间距、圆角、阴影、组件状态统一 |
| 主窗口框架完成 | 标题栏、导航栏、内容区布局可用 |
| 页面原型完成 | 6 个核心页面 mock 可交互展示 |
| 空状态 / loading / toast 统一 | 初版交互语义一致 |

## 3. 目标与范围

### 3.1 本里程碑包含

| 编号 | 内容 | 归类 | 涉及模块 |
|---|---|---|---|
| 1 | Tauri + React + TypeScript + Tailwind 项目脚手架 | 基础搭建 | 前端工程 |
| 2 | 设计 token 建立 | 设计系统 | Tailwind 配置 |
| 3 | shadcn/ui 与自定义基础组件接入 | 组件体系 | 前端组件 |
| 4 | 主窗口框架与导航布局 | 页面框架 | 主壳与路由 |
| 5 | 下载任务页 mock 原型 | 页面原型 | 下载任务页 |
| 6 | 批量抓取页 mock 原型 | 页面原型 | 批量抓取页 |
| 7 | 主页抓取页 mock 原型 | 页面原型 | 主页抓取页 |
| 8 | Cookie 配置页 mock 原型 | 页面原型 | Cookie 配置页 |
| 9 | 设置页 mock 原型 | 页面原型 | 设置页 |
| 10 | 首次引导页 mock 原型 | 页面原型 | 引导流程 |
| 11 | 基础动效、Toast、空状态与 loading 态 | 体验规范 | 全局组件 |

### 3.2 本里程碑不包含

- 真实 API 接入
- Python sidecar 服务化
- 真实任务下载、解析、Cookie 测试
- 自动更新、托盘、快捷键等系统能力

### 3.3 范围边界

- 所有页面数据使用 mock 或静态样例
- UI 外观、布局和交互模式在本里程碑冻结
- 后续里程碑只做接入，不推翻整体视觉结构

---

## 4. 设计依据与技术约束

- 视觉基准沿用现有设计规范中的品牌紫、浅色背景、信息密度控制原则
- 页面保持工具型、低装饰、强反馈
- 组件优先使用 shadcn/ui，项目级特殊组件单独实现
- 页面职责单一，避免把抓取、下载、配置混在同一视图中

## 5. 任务清单

### 任务 1：搭建前端工程脚手架

#### 目标

创建可独立运行的 Tauri + React + TypeScript + Tailwind 前端工程。

#### 涉及文件

| 文件 | 类型 | 说明 |
|---|---|---|
| `frontend/` | 新建 | 前端工程根目录 |
| `frontend/src/` | 新建 | React 源码 |
| `frontend/src-tauri/` | 新建 | Tauri 配置与 Rust 壳 |
| `frontend/package.json` | 新建 | 前端依赖 |
| `frontend/tauri.conf.json` | 新建 | Tauri 配置 |

#### 验证点

- 能启动开发模式
- 能打开空白窗口并渲染 React 页面

### 任务 2：建立设计系统 token

#### 目标

把颜色、字体、间距、圆角、阴影等设计语言固化为前端 token。

#### 涉及文件

| 文件 | 类型 | 说明 |
|---|---|---|
| `frontend/tailwind.config.ts` | 新建/修改 | 设计 token |
| `frontend/src/styles/` | 新建 | 全局样式入口 |

#### 验证点

- 颜色、字体、间距在所有页面一致
- Tailwind 主题可复用

### 任务 3：接入基础组件体系

#### 目标

引入 shadcn/ui，并补齐项目级基础组件。

#### 涉及文件

| 文件 | 类型 | 说明 |
|---|---|---|
| `frontend/src/components/ui/` | 新建 | shadcn/ui 组件 |
| `frontend/src/components/app/` | 新建 | 项目级组件 |

#### 验证点

- 按钮、输入框、弹窗、标签、进度条、滑块等组件可用

### 任务 4：构建主窗口框架

#### 目标

完成顶部标题栏、左侧导航、右侧内容区的桌面应用框架。

#### 涉及文件

| 文件 | 类型 | 说明 |
|---|---|---|
| `frontend/src/layouts/AppShell.tsx` | 新建 | 主壳布局 |
| `frontend/src/routes/` | 新建 | 页面路由 |
| `frontend/src/components/app/NavBar.tsx` | 新建 | 侧边导航 |
| `frontend/src/components/app/TitleBar.tsx` | 新建 | 标题栏 |

#### 验证点

- 导航切换正常
- 页面容器尺寸稳定
- 主窗口布局符合 UI 规范

### 任务 5：下载任务页 mock 原型

#### 目标

完成下载任务页的原型展示与局部交互。

#### 涉及文件

| 文件 | 类型 | 说明 |
|---|---|---|
| `frontend/src/pages/DownloadPage.tsx` | 新建 | 下载任务页 |
| `frontend/src/components/app/TaskItem.tsx` | 新建 | 任务行组件 |

#### 验证点

- 任务列表、进度条、状态、操作按钮、搜索、空状态可展示

### 任务 6：批量抓取页 mock 原型

#### 目标

完成批量链接解析页面的 mock 原型。

#### 验证点

- 多行输入、导入文件、解析结果、勾选、开始下载可交互

### 任务 7：主页抓取页 mock 原型

#### 目标

完成主页抓取页面的 mock 原型。

#### 验证点

- 过滤栏、抓取按钮、进度展示、结果列表可交互

### 任务 8：Cookie 配置页 mock 原型

#### 目标

完成 Cookie 列表、添加弹窗、测试、教程折叠面板的原型。

### 任务 9：设置页 mock 原型

#### 目标

完成下载目录、并发数、分块大小、元数据格式、日志导出等设置原型。

### 任务 10：首次引导页 mock 原型

#### 目标

完成首次启动的四步引导流程原型。

### 任务 11：基础动效与状态

#### 目标

统一 Toast、Loading、空状态、页面切换、列表 hover 等基础反馈。

## 7. 风险

| 风险 | 说明 | 对策 |
|---|---|---|
| 早期 UI 返工 | 原型不冻结会导致后续反复改 | v0.2.3 即冻结布局与外观 |
| 组件选择失控 | shadcn/ui 与自定义组件边界不清 | 先定组件使用边界 |
| 桌面布局适配 | 页面信息密度与窗口尺寸不匹配 | 先按桌面工具标准尺寸设计 |
