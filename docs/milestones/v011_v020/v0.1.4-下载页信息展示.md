## 2. 里程碑概述

### 2.1 里程碑定位

本里程碑是 v0.1.3 后的第四个迭代，聚焦下载任务页信息展示：将任务行从显示抖音链接改为显示视频标题，缩略图从占位图标改为视频封面。这是用户最痛点之一（v0.1.0 下载页空空地显示链接），也为 v0.1.7 图文流程提供标题/封面数据通道基础。

```
里程碑序列：
  v0.1.3 配置整合                 ✅ 前置依赖（已完成）
  v0.1.4 下载页信息展示           ◄── 本里程碑
  v0.1.5 链接解析增强             ◄── 后续
  ...
```

### 2.2 前置依赖

| 依赖项 | 来源 | 说明 |
|---|---|---|
| v0.1.3 完成 | 上一里程碑 | 配置整合已完成 |

## 4. 设计依据与技术约束

### 4.1 标题显示依据（用户反馈 #2）

用户反馈明确要求："下载的页面不要空空地显示一个抖音链接，将对应视频的标题先抓取下来显示给用户看"。

### 4.2 封面显示依据（用户反馈 #3）

用户反馈明确要求："下载对象的图标用对应视频的封面（看是否能够获取到）"。

### 4.3 任务行组件规范（UIUX 规范 4.5.1 节）

UIUX 规范第 4.5.1 节任务行组件规定：
- 标题：14px/600，超长省略
- 缩略图：64x64，圆角 4px，加载前显示灰色占位图 #E5E7EB

### 4.4 缩略图异步加载约束（设计文档 8.2 节）

设计文档第 8.2 节规定 UI 不直接调用网络请求，缩略图加载属例外（本地缓存 + 异步加载），需通过 `thumbnail_loader.py` 的 QThread/QRunnable 实现。

### 4.5 数据通道贯通验证

需确认以下数据流是否贯通：
```
VideoParser.parse() → VideoInfo(title, cover_url)
    ↓
DownloadBridge.parse_links() → result dict
    ↓
Scheduler.add_task_items() → TaskItem(title, cover_url) 写入 DB
    ↓
TaskItemRepository.get_by_task() → TaskItem(title, cover_url)
    ↓
TaskItemWidget.update_from_task_item() → 显示 title, 加载 cover_url
```

### 任务 2：解析阶段写入标题与封面

#### 2.1 目标

`VideoParser.parse()` 返回的 `title`、`cover_url` 在 `add_task_items()` 时写入 `TaskItem`。

#### 2.2 文件清单

| 文件 | 类型 | 说明 |
|---|---|---|
| `worker/download_bridge.py` | 确认/修改 | `parse_links()` 返回的 result dict 含 `title`、`cover_url` |
| `downloader/scheduler.py` | 确认/修改 | `add_task_items()` 接收 `title`、`cover_url` 并写入 DB |

#### 2.3 数据流改造

**`worker/download_bridge.py`**：
- `parse_links(text)` 返回的 result dict 确保含 `title`、`cover_url` 字段
- `start_download(aweme_ids)` 改为 `start_download(items: list[dict])`，每个 item 含 `aweme_id`、`title`、`cover_url`

**`downloader/scheduler.py`**：
- `add_task_items(items: list[dict])` 接收 item dict，写入 `TaskItem.title`、`TaskItem.cover_url`
- 若 item 缺少 `title` 或 `cover_url`，写入空字符串（不报错）

#### 2.4 验证点

- 解析阶段返回的 result dict 含 `title`、`cover_url`
- 入队时 `TaskItem.title`、`TaskItem.cover_url` 正确写入 DB
- DB 查询能读取到 `title`、`cover_url`

### 任务 3：任务行显示标题

#### 3.1 目标

任务行 `_title_label` 显示 `TaskItem.title`，超长省略；若 `title` 为空则回退显示 aweme_id 或"未命名"。

#### 3.2 文件清单

| 文件 | 类型 | 说明 |

title = item.title if item.title else f"未命名 ({item.aweme_id})"

- `_title_label` 设置 `setWordWrap(False)`

### 任务 4：任务行缩略图改用视频封面

#### 4.1 目标

任务行 `_thumb_label` 加载 `TaskItem.cover_url`；加载前显示占位图；加载失败保持占位图不报错。

#### 4.2 文件清单

| 文件 | 类型 | 说明 |
|---|---|---|
| `ui/widgets/task_item_widget.py` | 修改 | `_thumb_label` 加载逻辑 |
| `ui/widgets/thumbnail_loader.py` | 确认/修改 | 支持网络 URL 加载 |

#### 4.3 加载逻辑

**`update_from_task_item(item: TaskItem)` 修改**：
```python
# 缩略图加载逻辑
if item.cover_url:
    self._thumbnail_loader.load(item.cover_url, self._on_thumbnail_loaded)
else:
    self._thumb_label.setPixmap(self._placeholder_pixmap)
```

**`_on_thumbnail_loaded(pixmap: QPixmap)`**：
- 若 pixmap 非空，设置到 `_thumb_label`
- 若 pixmap 为空（加载失败），保持占位图不报错

#### 4.4 thumbnail_loader.py 确认

- 确认 `ThumbnailLoader` 支持网络 URL 加载（通过 httpx 或 QNetworkAccessManager）
- 确认加载是异步的（QThread/QRunnable）
- 确认加载失败时回调空 pixmap，不抛异常
- 确认 widget 销毁时取消未完成的加载任务

#### 4.5 验证点

- 任务行左侧缩略图显示视频封面（非占位图标）
- 缩略图异步加载不阻塞 UI
- 加载失败显示占位图不报错
- 多行同时加载缩略图不卡 UI

## 8. 风险与注意事项

### 8.1 技术风险

| 风险 | 影响 | 缓解措施 |
|---|---|---|
| `TaskItem` 缺少 `title`/`cover_url` 字段需 DB 迁移 | 已有任务记录字段为空 | 迁移时设置 DEFAULT ''；UI 显示"未命名"与占位图 |
| 封面 URL 因风控失效 | 缩略图加载失败 | 静默降级显示占位图，不报错不弹窗 |
| 缩略图加载请求错乱（widget 复用） | 显示错误图片 | widget 更新时取消旧请求，用请求 ID 匹配 |
| QLabel 超长省略不生效 | 标题溢出 | 使用 `setElidedText` 或自定义 paintEvent |
| `thumbnail_loader.py` 不支持网络 URL | 无法加载封面 | 确认支持 httpx 异步加载；若不支持需补充 |

### 8.2 实现注意事项

1. **数据通道验证**：本里程碑核心是确认数据流贯通，若 v0.0.1~v0.0.8 已实现则改动很小
2. **DB 迁移幂等性**：迁移脚本需幂等，重复执行不报错（`ALTER TABLE` 前检查列是否存在）
3. **占位图统一**：缩略图占位图使用 #E5E7EB 灰色 64x64，与 UIUX 规范一致
4. **标题回退策略**：`title` 为空时显示"未命名 (aweme_id)"，而非空 aweme_id，避免完全无信息
5. **缩略图缓存**：考虑简单内存缓存，避免同一 cover_url 重复加载（可选优化）
