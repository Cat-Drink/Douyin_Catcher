## 2. 里程碑概述

| 目标 | 衡量指标 |
|---|---|
| Cookie 配置页可用 | 列表、添加、测试、删除、全部测试正常 |

## 3. 目标与范围

### 3.1 本里程碑包含

| 编号 | 内容 | 归类 | 涉及模块 |
|---|---|---|---|
| 1 | Cookie 列表、添加、测试、删除接入 | 业务能力 | Cookie 配置页 |
| 2 | 全部测试接入 | 业务能力 | Cookie 配置页 |

### 3.2 本里程碑不包含

- 所有操作、配置、测试均基于真实 API
- 引导流程完成后状态持久化
- 全局错误处理涵盖 API 不可用、Cookie 失效等场景

## 4. 设计依据与技术约束

- Cookie 测试结果在行内展示，不弹窗
- 设置项修改后立即生效
- 引导流程可跳过，且跳过时提示功能受限
- 全局 Toast 轻量级，不打断用户操作
- 全局错误处理区分“可恢复”和“不可恢复”两类

## 5. 任务清单

### 任务 1：Cookie 列表与操作接入

#### 目标

让 Cookie 配置页通过 API 展示真实数据，支持添加、测试、删除。

#### 验证点

- Cookie 列表显示真实数据
- 添加新 Cookie 可保存，测试状态正确
- 删除有二次确认，删除后列表更新

### 任务 2：全部测试接入

#### 目标

批量测试所有 Cookie，前端逐行更新状态。

#### 验证点

- 全部测试按钮可用
- 每行状态灯与文字同步更新

### 任务 3：教程折叠面板

#### 目标

保留 Cookie 获取教程的折叠面板，内容与原版一致。

#### 验证点

- 折叠面板可展开/收起
- 教程图文内容完整

### 任务 4：设置项读写接入

#### 目标

让设置页的下载目录、并发数、分块大小、元数据格式、日志导出等配置项真实可用。

#### 验证点

- 设置项修改后保存、重新打开仍生效
- 下载目录选择器打开文件对话框
- 日志导出功能正常

### 任务 5：首次引导流程接入

#### 目标

让引导流程走真实 API，完成目录设置、Cookie 配置和完成页。

#### 验证点

- 欢迎页 → 目录设置 → Cookie 配置 → 完成页，流程完整
- 完成后再次启动直接进入主窗口
- 可跳过 Cookie 配置，主窗口显示提示

### 任务 6：全局 Toast 系统

#### 目标

统一操作反馈的 Toast 组件，覆盖成功、信息、警告三种类型。

#### 验证点

- 所有页面的操作反馈通过 Toast 显示
- 自动消失、手动关闭均可

### 任务 7：全局错误处理

#### 目标

统一处理 API 错误、网络不可用、Cookie 全部失效等系统级问题。

#### 验证点

- API 不可用时页面有明确提示
- 所有 Cookie 失效时弹窗引导用户去配置页
- 非技术用户能看到“人话”解释和下一步建议

## 7. 风险

| 风险 | 说明 | 对策 |
|---|---|---|
| Cookie 测试与真实支付态关联 | 测试可能触发服务端风险 | 测试仅检查有效性，不做实际请求 |
| 引导流程状态不一致 | 跳过/完成边界处理复杂 | 统一状态模型，确保幂等 |
| 全局错误覆盖不全 | 遗漏场景导致用户困惑 | 基于现有错误分类做全面覆盖 |
