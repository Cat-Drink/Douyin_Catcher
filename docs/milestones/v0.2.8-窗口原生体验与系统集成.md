## 2. 里程碑概述

### 2.1 里程碑定位

本里程碑负责把桌面壳的系统级体验补齐，确保前端不只是“网页跑在窗口里”，而是具备完整桌面应用能力。

### 2.2 前置依赖

| 依赖项 | 来源 | 说明 |
|---|---|---|
| v0.2.3 完成 | 前一里程碑 | 前端基础框架完成 |
| v0.2.4 完成 | 前一里程碑 | Sidecar 接口可用 |
| v0.2.5~v0.2.7 完成 | 前置里程碑 | 业务页面与配置闭环完成 |

### 2.3 交付目标

| 目标 | 衡量指标 |
|---|---|
| 窗口体验完整 | 尺寸、状态、显示行为稳定 |
| 托盘能力可用 | 可最小化到托盘并恢复 |
| 文件对话框可用 | 目录选择、导入、导出正常 |
| 快捷键可用 | 全局 / 局部快捷键生效 |
| 自动更新可用 | 能检查并提示新版本 |

## 3. 目标与范围

### 3.1 本里程碑包含

| 编号 | 内容 | 归类 | 涉及模块 |
|---|---|---|---|
| 1 | 原生窗口状态管理 | 桌面体验 | Tauri |
| 2 | 系统托盘 | 桌面体验 | Tauri |
| 3 | 文件对话框 | 系统能力 | Tauri |
| 4 | 系统快捷键 | 交互增强 | Tauri |
| 5 | 自动更新 | 发布能力 | Tauri |
| 6 | 可选深色模式 | 体验增强 | 前端主题 |

### 3.2 本里程碑不包含

- 核心业务接口新增
- 页面结构重排
- 解析与下载逻辑变更

### 3.3 范围边界

- 仅增强桌面系统层体验
- 不改业务模型
- 不推翻已经冻结的 UI 框架
