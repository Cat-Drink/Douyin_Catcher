## 2. 里程碑概述

### 2.1 里程碑定位

本里程碑负责把抓取与解析页面从 mock 切换到真实数据，完成链接输入、解析、结果展示、勾选下载、主页过滤等操作。

### 2.2 前置依赖

| 依赖项 | 来源 | 说明 |
|---|---|---|
| v0.2.3 完成 | 前一里程碑 | 前端页面原型冻结 |
| v0.2.4 完成 | 前一里程碑 | 解析与抓取 API 已可用 |

### 2.3 交付目标

| 目标 | 衡量指标 |
|---|---|---|
| 批量解析可用 | 粘贴链接后可解析展示 |
| 主页抓取可用 | 主页链接和过滤条件可抓取展示 |
| 结果勾选可用 | 勾选后可入队下载 |
| 导入文件可用 | 支持从文本文件导入链接 |
| 加载与错误反馈可用 | 解析/抓取状态清楚 |

---

## 3. 目标与范围

### 3.1 本里程碑包含

| 编号 | 内容 | 归类 | 涉及模块 |
|---|---|---|---|
| 1 | 批量链接解析接入 | 解析能力 | 批量抓取页 |
| 2 | 主页抓取接入 | 抓取能力 | 主页抓取页 |
| 3 | 结果勾选与入队接入 | 操作能力 | 结果列表 |
| 4 | 导入文件接入 | 输入能力 | 批量抓取页 |
| 5 | 过滤栏与本地过滤接入 | 筛选能力 | 主页抓取页 |
| 6 | 加载 / 错误 / 空状态接入 | 体验补全 | 两个页面 |

### 3.2 本里程碑不包含

- 下载任务页的业务接入深化
- Cookie 管理页面与设置页接入
- 系统功能增强

### 3.3 范围边界

- 抓取页只负责“输入 → 解析/抓取 → 结果展示 → 选择入队”
- 不在本里程碑引入新的下载规则或额外数据模型
